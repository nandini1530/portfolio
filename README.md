# Nandini Pandey — Portfolio

Personal portfolio website for **Nandini Pandey**, Program Manager (IN Payments) at Amazon.

A single, self-contained `index.html` (HTML + CSS + JS, no build step) with a cinematic
full-screen hero, stats bar, experience timeline, key programs, skills, and contact section.

## Live site

Once deployed with GitHub Pages, it will be available at:

```
https://<your-github-username>.github.io/portfolio/
```

## Run locally

Just open `index.html` in any browser. No installation or build required.

## Personalize

- **Profile photo** — add an image named `profile.jpg` in this folder (fills the circular avatar).
- **Background image** — add an image named `hero-bg.jpg` for the full-screen hero background.
- **Links** — update the Slack / Phonetool / LinkedIn links in the hero `.socials` section of `index.html`.
- **Content** — edit the About, Experience, Programs, and Skills sections directly in `index.html`.

## Deploy with GitHub Pages

1. Push this folder to a GitHub repository.
2. In the repo, go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
4. Choose branch `main` and folder `/ (root)`, then **Save**.
5. Wait a minute, then visit the URL shown on that page.

- HTML5, CSS3 (custom properties, flex/grid), vanilla JavaScript
